-- strategy --------------------------------------------------------------
  cloning        restriction + ligation, directional
  mode           nfusion
  5' enzyme      NdeI CA^TATG (2 nt 5' overhang)   vector position 5128
  3' enzyme      XhoI C^TCGAG (4 nt 5' overhang)   vector position 5207
  excised        78 bp of vector
  insert         465 bp amplified from the template

-- primers ---------------------------------------------------------------
  FWD  SOD1_F
        5'-TGACTG CATATG ATGGCGACGAAGGCCGTGTG-3'
        full length   32 nt
        annealing     ATGGCGACGAAGGCCGTGTG  (20 nt)
        Tm annealing   70.8 C   <- sets the annealing temperature
        Tm full        76.7 C   (cycle 3 onward, once the tail is copied)
        GC             65.0 %  (annealing region)
        3' dG          -3.9 kcal/mol   GC clamp 3/5

  REV  SOD1_R

        full length   42 nt

        Tm full        77.7 C   (cycle 3 onward, once the tail is copied)
        GC             46.7 %  (annealing region)
        3' dG          -4.1 kcal/mol   GC clamp 3/5

  suggested Ta   65.6 C  (lower annealing Tm minus 5)

   note  cloning as nfusion: the vector carries 6xHis tag, thrombin site in frame downstream of its own start codon, which is what its ribosome binding site is positioned for
   note  pET-28a's expression cassette runs on the reverse strand, so the vector is shown reverse-complemented here and the insert goes in the direction the promoter reads. Position p below is 5369 - p on your map
   note  no cassette is being replaced: 6xHis tag, thrombin site are what the insert fuses behind and have to stay. The insert goes into the polylinker after them
   note  inserting into the polylinker at 5128-5207; 11 of its sites are usable; no vector cassette is being replaced
   note  reading frame taken from the start codon at 5071 (first ATG 6 nt after the RBS); 2 feature(s) begin a whole number of codons after it: 6xHis tag at +12, thrombin site at +39
   note  63 bases run from the start codon to the end of the regenerated NdeI site, so no padding is needed: the site is already in frame
   note  the product carries the vector's N-terminal 6xHis tag, which sits between the start codon and the insert
   note  the vector's C-terminal 6xHis tag is downstream of the insert's own stop codon, so it is not translated. To use it, remove the stop with --mode cfusion; to keep the protein untagged at its C terminus, leave it as it is
   note  the insert keeps its own ATG, which becomes an extra methionine after 6xHis tag rather than the start codon. Harmless, but it is in the product
   note  the start codon sits 6 nt downstream of the vector's RBS at 5059-5064, inside the 5-13 nt window where initiation works best
   note  SOD1_F: annealing Tm 70.8 C is 8.8 C above the 62 C target; the 5' end of the insert is 65% GC and no length in 18-32 nt does better. Run at the suggested Ta rather than a textbook 60 C
   note  SOD1_R: annealing Tm 70.6 C is 8.6 C above the 62 C target; the 3' end of the insert is 47% GC and no length in 18-32 nt does better. Run at the suggested Ta rather than a textbook 60 C

-- colony PCR screen -----------------------------------------------------
  polymerase     Taq

  5' junction
    asks         is the insert joined to the vector at its 5' end, the right way round?
    primers      colVecF (3' end 5062) x colInsR (3' end 5543)
    clone        516 bp
    parental     no product  <- a band can only come from a real clone
     note  the parental vector gives no product, so a band means the insert is joined to the vector and not merely present in the colony

  3' junction
    asks         is the insert joined to the vector at its 3' end?
    primers      colInsF (3' end 5502) x colVecR (3' end 264)
    clone        563 bp
    parental     no product  <- a band can only come from a real clone
     note  the parental vector gives no product, so a band means the insert is joined to the vector and not merely present in the colony

  flanking
    asks         empty or full, by size, in one reaction
    primers      colVecF (3' end 5062) x colVecR (3' end 264)
    clone        999 bp
    parental     607 bp
     note  uncut or religated parental vector gives 607 bp, which is the band a negative colony shows

  primers to order:
    colVecF    5'-TGATGTCGGCGATATAGG-3'   18 nt  Tm 57.5
    colInsR    5'-TCACATTGCCCAAGTCTC-3'   18 nt  Tm 58.8
    colInsF    5'-TCCTCACTTTAATCCTCTATCC-3'   22 nt  Tm 57.6
    colVecR    5'-GAAGGGAAGAAAGCGAAAG-3'   19 nt  Tm 57.8

   WARN  colony PCR shows that a junction exists, not that the sequence is right. It cannot see a point mutation introduced by the cloning PCR, so a positive colony still has to be sequenced
   note  each junction pair has one primer in the vector backbone and one in the insert. A pair with both primers inside the insert would amplify leftover template and PCR product carried through the ligation just as well as a real recombinant, so every colony would score positive
   note  a junction pair also reports orientation: an insert ligated backwards gives no product at all, whereas a flanking vector pair gives the same size either way
   note  Taq is the usual choice here: fidelity does not matter for a screen, and tolerance of crude lysate does. Lyse the colony first, or the early cycles go on releasing template
